# RSVP — онлайн система за резервации

Начална основа за учебен проект за онлайн резервации на услуги. Планира се системата да поддържа клиентски и служителски профили, управление на услуги, заетост на служителите, календари и управление на резервации.

Проектът съдържа основа за frontend с HTML/CSS/JavaScript и ASP.NET Core Web API. Добавени са началните EF Core модели; все още няма реализирани процеси за резервации, frontend страници, миграции или начални данни.

## Структура на проекта

```text
backend/Rsvp.Api/              ASP.NET Core Web API (.NET 8)
frontend/                       Папки за frontend кода
docs/                           Документация за проекта, дизайна и екипа
```

Вижте [общия преглед на проекта](docs/project-overview.md) за обхвата и [началния продуктов списък](docs/backlog.md).

## Стартиране на backend приложението

Необходимо е да имате инсталиран .NET 8 SDK.

```sh
cd backend/Rsvp.Api
dotnet restore
dotnet run
```

Страницата OpenAPI/Swagger за разработка е достъпна на адреса, изведен от `dotnet run`, с добавено `/swagger`. Засега API няма крайни точки за функционалностите на приложението. Връзката към SQLite се задава в `appsettings.json` и може да бъде презаписана чрез конфигурацията на ASP.NET Core или User Secrets. При стартиране базата данни не се създава; API работи и без файл на база данни.

Подготвени са пакетите за EF Core и локален манифест на инструмента `dotnet-ef` за бъдеща работа по схемата. За възстановяване на локалния инструмент изпълнете `dotnet tool restore` от папката на API проекта. Не създавайте и не прилагайте миграции, преди екипът да е съгласувал модела на данните.

## Състояние на разработката

- Backend: създадена е основа на ASP.NET Core Web API, готова за разработка.
- База данни: EF Core със SQLite за демонстрационния проект; началните модели са в `backend/Rsvp.Api/Models/`.
- Frontend: подготвени са папките; работата по страниците, стиловете и скриптовете не е започнала.
- Публикуване: извън обхвата. Отделната папка на уебсайта не се използва.

Решенията и отворените въпроси по проекта са описани в документите в `docs/`.
