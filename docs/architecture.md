# Архитектура на системата

## Начална структура

- `frontend/`: статичен код с HTML/CSS/JavaScript; без framework или процес за изграждане.
- `backend/Rsvp.Api/`: ASP.NET Core 8 Web API с контролери.
- `docs/`: документация за проекта, изискванията, архитектурата, API, базата данни и екипа.

Frontend и API ще се разработват съвместно, но ще останат отделни приложения. Маршрутите на API и интеграцията с браузъра все още не са реализирани.

## Организация на backend

API проектът използва пространството от имена `Rsvp.Api` и е подготвен за:

- `Controllers/` — HTTP крайни точки и транспортни отговорности
- `Data/` — EF Core `ApplicationDbContext` и бъдеща конфигурация за съхранение на данни
- `Models/` — началните домейн модели за клиенти, служители, услуги, работно време и резервации
- `DTOs/` — договори за заявки и отговори
- `Interfaces/` — абстракции на услуги, когато са необходими
- `Services/` — сценарии на приложението и координация на логиката
- `Configuration/` — настройки и помощни средства за конфигурация

Контролерите трябва да останат компактни, а логиката на приложението да се премести в услуги след съгласуване на изискванията. Не добавяйте допълнителни архитектурни слоеве, преди екипът да има нужда от тях.

## Среда за изпълнение и конфигурация

- Целева платформа: `net8.0`; версиите на SDK и средата за изпълнение зависят от машината за разработка.
- Swagger UI е достъпен само в среда за разработка.
- Настройките за връзка със SQLite се зареждат чрез стандартната конфигурация на ASP.NET Core.
- API регистрира EF контекста, но при стартиране не отваря връзка и не създава база данни.
- Хостването в продукционна среда, CORS политиката, удостоверяването, регистрирането/наблюдението и изборът на база данни предстои да бъдат уточнени.
