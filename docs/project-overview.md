# Общ преглед на проекта

## Цел

Планиране и разработване на онлайн система, чрез която клиентите да резервират услуги, а служителите да управляват информацията и заетостта, необходими за предоставянето им.

## Обхват на проекта

- Клиентски и служителски профили
- Управление на услуги
- Заетост и календари на служителите
- Онлайн резервации и управление на резервации

Това са договорените области на проекта, а не вече реализирани функционалности.

## Извън обхвата на началната основа

- Бизнес логика и крайни точки на системата за резервации
- Frontend страници, стилове, скриптове и демонстрационни реализации
- Създаване на таблици, миграции и начални данни; моделите са само начална основа
- Публикуване и хостване в продукционна среда

## Потвърдени решения

- Изходният код на frontend и backend се намира заедно в тази проектна папка.
- Frontend използва стандартни HTML, CSS и JavaScript.
- Backend използва ASP.NET Core Web API и C#.
- Инициализирането на Git ще се извърши отделно.
- Публикуваният RSVP уебсайт се поддържа отделно в `/srv/websites/rsvp/`.

## Предположения и отворени въпроси

- SQLite е временно конфигуриран само за локална разработка.
- Технологията за продукционната база данни, хостването, удостоверяването, правилата за резервации и окончателните детайли на функционалностите трябва да бъдат съгласувани от екипа.
