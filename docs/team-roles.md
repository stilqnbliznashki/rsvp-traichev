# Роли и отговорности в екипа

| Роля | Основни отговорности | Име |
|---|---|---|
| Frontend разработчик | HTML, CSS, JavaScript; клиентски и служителски процеси; проверки за достъпност и съвместимост с браузъри; координация на нуждите към API с backend разработчика | Байчев |
| Backend разработчик | ASP.NET Core API; достъп до данни и миграции на базата след одобрение на схемата; валидация, API документация и backend тестове | Аз |
| Scrum Master | Планиране, документация, координация, бележки от срещи, поддръжка на продуктовия списък и проследяване на напредъка | За уточняване |

## Работни споразумения

- Екипът да съгласува приоритетите, определението за „готово“ и практиките за преглед.
- Решенията за API и модела на данните да се документират, а промените, засягащи няколко роли, да се обсъждат своевременно.
- Решенията, отговорниците и датите за проследяване да се записват в бележките от срещите.
- Имена, данни за контакт, честота на срещите и инструмент за проследяване на работата: **за уточняване**.
